# Термины FishSite

Использовать при именовании интерфейсов, моделей и документов обмена с МойСклад.

| Термин | Значение |
|---|---|
| Розничная заявка | Исходное обращение покупателя с контактами, товарами, желаемым весом и предварительными суммами. Не означает продажу |
| Учётный заказ | Документ «Заказ покупателя» в МойСклад; менеджер ведёт в нём согласованный состав и результат обработки |
| Контрагент | Карточка покупателя или организации в МойСклад, связанная с учётным заказом |
| Учётная позиция | Товар справочника МойСклад с учётным названием, единицей и прайсом |
| Карточка сайта | Публичное название, категория, описание, фотографии и цена товара |
| Желаемый вес | Вес, указанный покупателем в заявке |
| Фактический вес | Вес, согласованный менеджером для исполнения учётного заказа |
| Предварительная сумма | Расчёт по цене и желаемому весу на момент заявки; не выручка и не окончательный итог |
| Состояние передачи | Результат передачи заявки в МойСклад |
| Учётный статус | Состояние обработки учётного заказа, установленное в МойСклад; отличается от состояния передачи |
