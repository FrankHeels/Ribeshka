# Значки соцсетей и почты — 19.10.2026

Пять отдельных значков для контактов FishSite: WhatsApp, VK, Telegram, MAX и
общая почта. Созданы встроенным `image_gen`, затем векторизованы выбранным
пользователем Vectorize: один цвет, smoothing 1, прозрачность, без обрезки холста.
SVG приведены к точному токену латуни `#D7B77B`; PNG экспортированы из SVG.

## Файлы

Все финальные значки находятся в `static/img/social/`:

| Значок | PNG для админки | Вектор |
|---|---|---|
| WhatsApp | `whatsapp-brass-v1.png` | `whatsapp-brass-v1.svg` |
| VK | `vkontakte-brass-v1.png` | `vkontakte-brass-v1.svg` |
| Telegram | `telegram-brass-v1.png` | `telegram-brass-v1.svg` |
| MAX | `max-brass-v1.png` | `max-brass-v1.svg` |
| Почта | `email-brass-v1.png` | `email-brass-v1.svg` |

PNG — 512×512 RGBA, полностью прозрачные углы; непрозрачные пиксели имеют
RGB `(215, 183, 123)`. В SVG сохранены масштабируемые контуры. Предпросмотр
на тёмном фоне и в размере 32 px — [social-icons-preview.png](social-icons-preview.png).
Общий архив PNG/SVG и промптов — [fishsite-social-icons-v1.zip](fishsite-social-icons-v1.zip).

## Использование

«Контакты и общие настройки → Ссылки → Изображение»: загрузить соответствующий
PNG. В админке поддерживаются PNG, WebP и JPEG; SVG предназначены для прямого
использования в вёрстке или дальнейшего редактирования. Адреса ссылок задаёт
владелец; генерация не добавляет новые контакты и не меняет существующие строки.

## Промпты и происхождение

Полный набор промптов, настройки и ID ревизий Vectorize:
[social-icons-generation.json](social-icons-generation.json). Первичные PNG
получены встроенным генератором; CLI/API-режим не использовался. Мелкие растровые
артефакты убраны трассировкой. Цвет выровнен в SVG, прозрачные PNG экспортированы
через Sharp. Python/Pillow использован только для проверки формата, цвета и альфа-канала.

Форма MAX сверена с [официальным брендбуком](https://go.max.ru/brandbook)
и [образцом знака](https://max.ru/s/img/big-logo.png); фон и фирменный градиент
MAX не включены в значок. Итоговые значки — одноцветные адаптации для дизайн-кода
FishSite, а не новые логотипы самих сервисов.
