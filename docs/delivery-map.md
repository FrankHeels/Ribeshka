# Карта зон доставки

На `/delivery/` под всеми текстовыми материалами размещена интерактивная карта
Яндекс Карт JavaScript API v3. Другие страницы не подключают API и не получают
ключ. Карта не рассчитывает стоимость доставки и не проверяет адреса.

## Настройка

В `.env` задайте `YANDEX_MAPS_API_KEY` — ключ JavaScript API v3. Django читает
его при запуске; после изменения `.env` перезапустите web-процесс. В Compose
`.env` передаётся через `env_file`; для применения изменений пересоздайте web
(`docker compose up -d --force-recreate web`). Ключ не хранится в репозитории.
Это браузерный ключ: на странице доставки он виден посетителю и передаётся
через безопасный Django `json_script`.

В кабинете разработчика Яндекса у соответствующего ключа укажите разрешённый
домен сайта без схемы, порта и пути. Для разработки добавляйте только нужные
тестовые домены отдельно. Ограничения применяются со стороны Яндекса, а не
через `ALLOWED_HOSTS`; изменение `.env` их не настраивает. По документации
ограничения вступают в силу до 15 минут и касаются тарифицируемых запросов;
одно лишь отображение карты на другом домене не доказывает отсутствие ограничения.

Для локального прогона разрешите `localhost` и открывайте сайт по
`http://localhost:8000/delivery/`. Одинарные/двойные кавычки вокруг значения в
`.env` допустимы: `python-dotenv` удаляет их. Не отключайте передачу `Referer`:
текущая политика `strict-origin-when-cross-origin` передаёт Яндексу origin сайта.

Документация: [подключение API](https://yandex.ru/maps-api/docs/js-api/common/connection/javascript.html),
[ограничения ключа](https://yandex.ru/maps-api/docs/js-api/limit.html),
[полигоны](https://yandex.ru/maps-api/docs/js-api/object/geo-objects/YMapFeature.html).

## Контуры и оформление

`static/js/delivery-zones.js` содержит три статических полигона в формате
`[долгота, широта]`. Админка ими не управляет. Контуры, порядок наложения,
цвета, прозрачность и толщина границ взяты 08.10.2026 из публичных данных карты
на [предоставленном референсе](https://fish-empire39.ru/delivery), поэтому ручная
оцифровка изображения не потребовалась. ID карты-конструктора указан в JS.

| Зона | Заливка | Контур |
|---|---|---|
| Калининград | `#1e98ff`, 60% | `#177bc9`, 5 px |
| Внешняя зона | `#ed4543`, 60% | `#ed4543`, 5 px |
| Гурьевск | `#1bad03`, 60% | `#1bad03`, 5 px |

Прозрачность контуров — 230/255. Внешняя зона рисуется первой; синяя зона
накладывается поверх неё, как в референсе. Контуры воспроизводят схему референса,
а не официальные административные границы. Цены и тексты конкурента не перенесены.
При изменении зон обновляйте также легенду и версию импорта `delivery-zones.js`.

Карта подстраивает начальный охват под все зоны, поддерживает перетаскивание,
масштабирование двумя пальцами, двойным нажатием и кнопками, кнопку «Все зоны».
Колесо мыши сохраняет прокрутку страницы. Панорамы, геокодер, поиск и маршрутизация
не подключены. Штатная атрибуция Яндекса сохранена. Постоянная внешняя ссылка
открывает обычную карту района; наши статические зоны отображаются на сайте.

## Отказы и проверка

Без ключа сторонний API не загружается. Без JavaScript сохраняются тексты,
легенда, объяснение и внешняя ссылка. API загружается при приближении блока к
экрану; сетевой отказ, ошибка инициализации или отсутствие первых тайлов за
20 секунд возвращают понятное сообщение вместо пустого блока. Таймаут не
позволяет позднему ответу API перезаписать состояние отказа.

Проверять desktop и телефон: три зоны целиком, правильный порядок наложения,
цвета и атрибуция, масштабирование/возврат, отсутствие горизонтальной прокрутки.
Отдельно проверять пустой ключ, заблокированный API, неверный ключ и выключенный
JavaScript. Проверка живого API требует действующего ключа и сети.

Проверка 08.10.2026: 12 Django-тестов прошли в изолированной PostgreSQL;
CSS собран, JS прошёл синтаксическую проверку. На ширинах 320, 390 и 1440 px
нет горизонтальной прокрутки; проверены отсутствие ключа, выключенный JavaScript,
сетевой отказ, таймаут и поздний ответ. С имитацией API проверены три полигона,
порядок/стили и кнопки масштаба/возврата. Все координаты совпадают с публичными
данными референса (14, 8 и 27 вершин, включая замыкающие).

Живая загрузка пока не подтверждена: полученный ключ возвращает
`403 Invalid api key` и с `127.0.0.1`, и с `localhost`, при корректном `Referer`.
После настройки/активации ключа повторить визуальную проверку реальных тайлов,
полигонов, начального охвата и атрибуции на desktop и телефоне. Ограничения в
кабинете Яндекса в рамках этой проверки не изменялись.

Повторная диагностика 08.10.2026 после ожидания более 15 минут: в открытом
кабинете подтверждены активный JavaScript API, активный ключ, сохранённый
HTTP Referer `localhost` и отсутствие ограничения по IP. Значение ключа
совпадает с `.env`. Прямой запрос вне браузера с
`Referer: http://localhost:8000/` также получает `403 Invalid api key` от `/v3/`.
Для сравнения загрузчик `/2.1/` отвечает HTTP 200; это не подтверждает работу
всех функций v2.1 и не меняет выбранную версию v3 на сайте. Причина отказа v3
не раскрывается ответом сервиса; для выяснения нужен ответ поддержки Яндекса
или повторная проверка с новым ключом. Локальная настройка `localhost`
соответствует [официальному быстрому старту](https://yandex.ru/maps-api/docs/js-api/common/quickstart.html).

Диагностика 09.10.2026: ситуация изменилась. Один и тот же ключ из `.env`
совпадает со значением в HTML обоих локальных адресов. Прямой запрос `/v3/`
с `Referer: http://localhost:8000/` возвращает 200 JavaScript, а с
`Referer: http://127.0.0.1:8000/` — 403 `Invalid api key`. В браузере на
`http://localhost:8000/delivery/` загружаются реальные тайлы, атрибуция и
управление; состояние блока — `ready`, ошибок в консоли при проверке нет.
Для локальной работы использовать `localhost`: разрешение этого имени
не распространяется автоматически на `127.0.0.1`. Кавычки в `.env` и
передача ключа через Django не являются причиной текущего отказа.

При живой проверке также обнаружен и исправлен конфликт CSS: глобальное
`img, svg { max-width: 100%; }` сжимало SVG-слой полигонов шириной в два
контейнера до ширины контейнера и смещало зоны относительно подложки.
Для `.delivery-map-canvas svg` задано `max-width: none`; размеры и проекцией
слоя управляет API. CSS пересобран, версия статического файла обновлена.
