### Отдельная проблема карт Яндекса

После сохранения нового HTTP Referer и ожидания API продолжил отвечать `403 Invalid api key`
для `https://ribeshka39.ru/delivery/`; с тем же ключом и Referer `http://localhost:8000/delivery/` — `200`.
Это не ошибка TLS/CSRF сайта: отказ возвращает `api-maps.yandex.ru`. Сохранённое ограничение нового
домена подтверждено пользователем. Успешная живая карта на новом домене не заявляется.
Нужна отдельная проверка авторизации у Яндекса; ключ не заменялся, платные услуги/секреты не создавались,
обращение в поддержку Яндекса не отправлялось. До решения остаются предусмотренные шаблонами текст,
легенда, адрес и внешние ссылки на карты. Исходники отображения карт не менялись.

Корзина и вход используют cookies конкретного hostname. Сессии старого домена автоматически не
переносятся; открытую до переезда форму нужно заново открыть на новом адресе. Защита CSRF не ослаблялась.
