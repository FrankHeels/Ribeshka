# Карта страниц и состав экранов

Читать при работе с маршрутами, ассортиментом, навигацией и составом страниц.
Ниже описано целевое поведение MVP; наличие шаблона не означает готовность
его бизнес-сценария. Текущее состояние проверяй в коде и конфигурации; выбор требований — в [индексе проекта](INDEX.md).

В первой секции главной перед кнопкой перехода к ассортименту всегда показана отдельная пометка: цены ориентировочные, наличие нужного объёма и итоговую стоимость подтверждает менеджер, заявка не резервирует товар. Редактирование вводного текста главной не скрывает эту пометку.

В карточках категорий и рекомендаций рядом с ценой показана короткая пометка о предварительной цене и уточнении наличия у менеджера. Страница товара поясняет необходимость подтверждения цены и нужного объёма; в корзине пояснение размещено только рядом с предварительным итогом, без отдельного баннера перед отправкой. После отправки розничной заявки показываются «Заявка получена» и пояснение о предстоящем подтверждении наличия, количества и стоимости менеджером.

| Маршрут | Содержание и действие |
|---|---|
| `/` | Экранные секции: асимметричный hero 5/12 + 7/12 → все категории с опубликованными товарами в редакционной сетке → до 2 рекомендуемых опубликованных товаров → деревянная информационная секция с текстом о компании и до 4 подтверждённых преимуществ 2×2 → 3 шага заявки → доставка/самовывоз и контакты. В шапке раскрывается меню со всеми публичными категориями. На коротких экранах адаптировать сетку и отступы, не обрезать содержимое. Показывать только подтверждённые материалы заказчика, для отсутствующих фотографий — честное пустое состояние. |
| `/catalog/` | Публичной страницы общего списка нет; категории показаны в секции «Ассортимент» на главной и в меню шапки. |
| `/catalog/categories/<slug>/` | Самостоятельная категория: заголовок, непосредственно относящиеся к ней опубликованные товары, хлебные крошки «Главная → Категория». Описание под заголовком, переключатель и метки хитов не выводятся; `?popular=1` не фильтрует товары. Хиты выбираются только для секции «Рекомендуемые товары» главной. Slug категории уникален. Подкатегорий нет. |
| `/catalog/products/<slug>/` | Галерея, название, описание, цена за кг, кнопки −/+ и компактный ввод добавляемого целого веса от 1 кг с шагом 1 кг без нативных стрелок, предварительная сумма, добавление в корзину. Повторное добавление накапливает вес той же позиции; начальное значение карточки всегда 1 кг. Slug товара уникален. |
| `/cart/` | Позиции, кнопки −/+ по 1 кг и компактный ручной ввод общего веса, удаление, предварительные суммы и форма заявки под итогом: контакты, доставка/самовывоз, адрес при доставке, комментарий, согласие и отправка. Автосохранение отправляет изменения сразу и обновляет суммы без исчезновения, анимации, видимой статусной плашки и скачков раскладки. |
| `/checkout/` | Совместимый маршрут: GET перенаправляет на `/cart/#request`, POST использует обработчик формы корзины. |
| `/checkout/success/<token>/` | Общее подтверждение получения заявки по непрогнозируемому токену и пояснение о подтверждении наличия, количества и стоимости менеджером. Не показывать номер заявки, внутренние идентификаторы или персональные данные. |
| `/wholesale/` | Пояснение для оптовых покупателей и **отдельная форма**: контактное лицо, телефон, необязательные компания/email, согласие. Описания потребности, оптовой корзины и прайса нет. |
| `/wholesale/success/<token>/` | Номер принятого оптового запроса по отдельному UUID-токену; без контактов и описания. Неизвестный токен — 404. |
| `/about/`, `/delivery/`, `/contacts/` | Сведения компании; условия доставки и самовывоза; контакты. Тексты и реквизиты предоставляет заказчик. |
| `/privacy/` | Политика обработки персональных данных из `docs/legal/personal-data-policy.md`; ссылка из форм и футера. |
| `/personal-data-consent/` | Отдельное согласие для розничных заявок и оптовых запросов из `docs/legal/personal-data-consent.md`; ссылка у обязательного флажка согласия в обеих формах и в футере. |
| `/yandex-metrica-consent/` | Согласие на будущую Яндекс Метрику из `docs/legal/yandex-metrica-consent.md`; ссылка в футере и навигации документов. Счётчик и уведомление с выбором аналитики пока не подключены. |

Все три документа пока являются проектами с явно отмеченными полями `{{...}}`.
Они доступны без JavaScript, содержат навигацию между документами и уведомление
о статусе проекта. Внутренние ссылки из Markdown ведут на соответствующие
страницы Сайта. До заполнения и проверки условий страницы имеют `noindex, nofollow`
и исключены из sitemap. При подготовке окончательных редакций нужно явно убрать
статус проекта и запрет индексации в представлениях/шаблоне и вернуть маршруты
в sitemap; заполнение Markdown само по себе эти настройки не меняет.

На `/delivery/` после материалов доставки размещена [карта трёх статических зон](../delivery-map.md)
на JavaScript API Яндекс Карт v3. Без ключа или JavaScript доступны текст и ссылка
«Открыть в Картах»; карта не определяет тариф и не проверяет адрес.

Для всех страниц: общая шапка, навигация и футер; на внутренних страницах — хлебные крошки. Обеспечить удобство на телефоне и компьютере. Публичные категории и товары должны иметь понятные заголовки, metadata, sitemap и оптимизированные изображения. Не переносить маршруты `/tproduct` и `/tpost` или блоки конкурента механически.

## По задаче

Кабинет владельца находится на `/admin/`; административный вход и настройка
TOTP — в `/two_factor/account/`. Публичные URL не изменились. Контакты и график
берутся из общих настроек, заголовок и вводный текст главной — из её блоков содержания.
Отдельного раздела «Обложка главной» нет; кнопка «Перейти к ассортименту» всегда
ведёт на `#assortment`. Рекомендации берутся
из двух явно выбранных мест. Предпросмотр скрытой карточки существует только
под защищённым административным URL. Возможности и включение — в
[руководстве кабинета](../backoffice.md).

- Имена URL, шаблоны, контекст и состояния форм — [контракт frontend](../frontend-contract.md).
- Внешний вид и адаптивность — [дизайн-система](../design-system.md).
- Расчёты и отправка форм — [сценарии заявок](order-flow.md).
