# Карта страниц и состав экранов

Читать при работе с маршрутами, ассортиментом, навигацией и составом страниц.
Ниже описано целевое поведение MVP; наличие шаблона не означает готовность
его бизнес-сценария. Текущее состояние проверяй в коде и конфигурации; выбор требований — в [индексе проекта](INDEX.md).

| Маршрут | Содержание и действие |
|---|---|
| `/` | Экранные секции: асимметричный hero 5/12 + 7/12 → все категории с опубликованными товарами в редакционной сетке → до 2 рекомендуемых опубликованных товаров → деревянная информационная секция с текстом о компании и до 4 подтверждённых преимуществ 2×2 → 3 шага заявки → доставка/самовывоз и контакты. В шапке раскрывается меню со всеми публичными категориями. На коротких экранах адаптировать сетку и отступы, не обрезать содержимое. Показывать только подтверждённые материалы заказчика, для отсутствующих фотографий — честное пустое состояние. |
| `/catalog/` | Публичной страницы общего списка нет; категории показаны в секции «Ассортимент» на главной и в меню шапки. |
| `/catalog/categories/<slug>/` | Самостоятельная категория: заголовок, непосредственно относящиеся к ней опубликованные товары, описание при наличии, хлебные крошки «Главная → Категория». Slug категории уникален. Подкатегорий нет. |
| `/catalog/products/<slug>/` | Галерея, название, описание, цена за кг, кнопки −/+ и компактный ввод добавляемого целого веса от 1 кг с шагом 1 кг без нативных стрелок, предварительная сумма, добавление в корзину. Повторное добавление накапливает вес той же позиции; начальное значение карточки всегда 1 кг. Slug товара уникален. |
| `/cart/` | Позиции, кнопки −/+ по 1 кг и компактный ручной ввод общего веса, удаление, предварительные суммы и форма заявки под итогом: контакты, доставка/самовывоз, адрес при доставке, комментарий, согласие и отправка. Автосохранение отправляет изменения сразу и обновляет суммы без исчезновения, анимации, видимой статусной плашки и скачков раскладки. |
| `/checkout/` | Совместимый маршрут: GET перенаправляет на `/cart/#request`, POST использует обработчик формы корзины. |
| `/checkout/success/<token>/` | Номер принятой заявки по непрогнозируемому токену; не раскрывать персональные данные по последовательному ID. |
| `/wholesale/` | Пояснение для оптовых покупателей и **отдельная форма**: контактное лицо, телефон, необязательные компания/email, согласие. Описания потребности, оптовой корзины и прайса нет. |
| `/wholesale/success/<token>/` | Номер принятого оптового запроса по отдельному UUID-токену; без контактов и описания. Неизвестный токен — 404. |
| `/about/`, `/delivery/`, `/contacts/` | Сведения компании; условия доставки и самовывоза; контакты. Тексты и реквизиты предоставляет заказчик. |
| `/privacy/` | Политика обработки персональных данных; ссылка на неё доступна из форм и футера. Текст предоставляет заказчик. |

На `/delivery/` после материалов доставки размещена [карта трёх статических зон](../delivery-map.md)
на JavaScript API Яндекс Карт v3. Без ключа или JavaScript доступны текст и ссылка
«Открыть в Картах»; карта не определяет тариф и не проверяет адрес.

Для всех страниц: общая шапка, навигация и футер; на внутренних страницах — хлебные крошки. Обеспечить удобство на телефоне и компьютере. Публичные категории и товары должны иметь понятные заголовки, metadata, sitemap и оптимизированные изображения. Не переносить маршруты `/tproduct` и `/tpost` или блоки конкурента механически.
