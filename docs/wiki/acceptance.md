# Приёмка MVP

Использовать при подготовке сквозной проверки релиза. Это критерии результата;
прошлые прогоны не подтверждают состояние нового окружения.

## Сквозные сценарии

| Сценарий | Ожидаемый результат | Подробные проверки |
|---|---|---|
| Розница: товар → корзина → заявка | Одно обращение с неизменяемыми снимками; доставка требует адреса, самовывоз — нет; после commit создана почтовая задача | [Заявки](order-flow.md), [корзина](cart.md) |
| Изменение цены, публикации или веса перед отправкой | Сервер требует нового подтверждения изменённого состава; скрытый товар недоступен и через прямой POST | [Корзина](cart.md) |
| Повторный и конкурентный POST | Одна заявка и одна почтовая задача; повтор возвращает прежний результат даже после очистки корзины | [Публичные формы](public-forms.md) |
| Согласие покупателя | Сохраняется именно подписанная редакция; изменение текущего Markdown её не подменяет | [Публичные формы](public-forms.md#редакция-согласия) |
| Опт | Контактная форма без корзины и описания потребности; отдельная заявка и почтовая задача | [Заявки](order-flow.md#оптовая-заявка) |
| Сбой SMTP, остановка и два worker | Заявка сохраняется; отложенный повтор и ручное восстановление работают; действующий lease защищает от второго захвата | [Уведомления](notifications.md) |
| Передача в МойСклад | Публичный POST остаётся локальным; отдельное решение владельца ставит один экспорт; неопределённый результат проверяется по прежнему `syncId` | [Контракт интеграции](../MoySklad-plan.md), [проверки](../MoySklad-implementation.md) |
| Работа владельца | TOTP и права проверяются сервером; контакты и снимки только для чтения; удаление требует отдельного подтверждения | [Панель владельца](../backoffice.md) |
| Мобильный экран и JavaScript | Основные страницы и отправка форм работают без JS; JS-пересчёт не показывает устаревшие суммы | [Контракт frontend](../frontend-contract.md), [дизайн-система](../design-system.md) |
| Запуск и восстановление | HTTPS, реальные материалы, секреты и SMTP настроены; БД и фотографии восстановлены из резервной копии | [Публичный запуск](../public-deployment-spec.md) |

Транзакционные и конкурентные сценарии проверять на отдельном PostgreSQL по
[инструкции тестового окружения](../test-environment.md). Проверка настоящего
SMTP, API МойСклад и публичного HTTPS выполняется отдельно от mock-тестов.

## Материалы перед публикацией

Подтвердить ассортимент, цены, права на фотографии, контакты, доставку и
юридические реквизиты из [границ MVP](mvp-scope.md#материалы-заказчика).
Юридические Markdown-файлы содержат незаполненные поля; заполнение и проверка
сроков обработки данных входят в подготовку запуска. После утверждения текстов отдельно снять режим проекта, запрет индексации
и исключение из sitemap по [контракту юридических страниц](../frontend-contract.md#legal-pages).
Метрика требует отдельной реализации управления согласием; наличие проекта текста не означает подключения.
