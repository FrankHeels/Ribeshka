## Текущее состояние

Локальный Compose поднимает PostgreSQL, Django/Gunicorn, Nginx, доступный только по HTTP и
отдельные профили worker. Это конфигурация для частной VM; она не выполняет production-деплой.
На VPS отдельно работает production-стек по протоколам выше. Его Compose теперь хранится в
`deploy/production/`; автоматический агент включается только после условий первого выпуска
из [инструкции CI/CD](../ci-cd.md). Фактический статус проверяй на сервере, а не по наличию файлов.

Параметры окружения смотри в шаблонах [локальной разработки](../../.env.example) и
[Compose](../../.env.compose.example). Секреты храни только в локальном .env с закрытыми правами
или в окружении/secret store сервера.
