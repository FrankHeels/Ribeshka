# Дизайн-система публичного сайта

Применяйте при изменении внешнего вида, адаптивности или доступности. Активное направление — тёмное дерево, сливочная типографика и латунные детали. Состав публичных страниц — в [`wiki/page-map.md`](wiki/page-map.md), видимое поведение и контекст шаблонов — в [`frontend-contract.md`](frontend-contract.md).

## Единственный источник значений

Токены задаются в [`frontend/brand-tokens.css`](../frontend/brand-tokens.css), шрифты — в [`frontend/fonts.css`](../frontend/fonts.css), компоненты и адаптивные правила — в [`frontend/input.css`](../frontend/input.css). Не копируйте значения токенов в этот документ и не создавайте второй набор CSS-переменных для той же роли. [`static/css/site.css`](../static/css/site.css) — собранный файл.

После изменения `frontend/input.css` соберите CSS командой `npm --prefix frontend run build:css`. При изменении публичного JS/CSS обновите cache-busting версию соответствующего файла в шаблоне.

## Цвет, шрифт и материалы

- `Cormorant Garamond` используется в заголовках и контактном номере; `Golos Text` — в основном интерфейсе и длинном тексте; `Onest` — в коротких редакционных фрагментах и тексте бумажной записки.
- Основной текст рассчитан примерно на 18px, малый текст и подписи — на 16px. Сохраняйте масштабируемые CSS-токены; не уменьшайте текст, чтобы уместить контент.
- Главные фоновые текстуры: `smoked-walnut.webp` и `roasted-oak.webp`. Промпты и пары «исходник PNG / production WebP» находятся в [`design-reference/dark-wood-generation.md`](design-reference/dark-wood-generation.md).
- Фон бумажной записки — активный декоративный ассет; полный промпт, PNG-источник и WebP указаны в [`design-reference/shop-note-generation.md`](design-reference/shop-note-generation.md). Сам текст остаётся HTML.
- Контактные и социальные SVG/PNG и параметры генерации описаны в [`design-reference/social-icons-generation.md`](design-reference/social-icons-generation.md); полный набор промптов и параметров Vectorize хранится в соседнем JSON.
- Тематический рыбный натюрморт страницы «О компании» — `static/img/about/seafood-table.webp`; происхождение и полный промпт — в [описании ассета](design-reference/about-image-generation.md).
- Если меняется семейство шрифта или лицензия, сверьтесь с [`static/fonts/README.md`](../static/fonts/README.md) и самими файлами лицензий.

## Типографика и компоновка

- Длинный текст и подписи переносятся, элементы растут по содержимому. Не фиксируйте высоту так, чтобы она обрезала текст, ошибки, форму или содержимое при увеличении шрифта.
- На телефоне и при увеличении текста до 200% страница должна перестраиваться без горизонтальной прокрутки всего документа. Таблица или карта может прокручиваться только внутри собственного обозначенного контейнера.
- Контролы должны работать на касании; не оставляйте важное действие только на `hover`. Сохраняйте заметный keyboard focus и заданные названия кнопок.
- Интерактивные карты должны иметь адрес/легенду и ссылки вне карты; сохраняйте пропорции SVG Яндекса (`max-width: none` для содержимого карты).

## Мобильная прокрутка главной

Для экранных секций главной с прокручиваемым содержимым минимальная высота рассчитывается от стабильного малого viewport: fallback `100vh`, затем `min-height: calc(100svh - var(--header-height))`. Не используйте `dvh` для высоты таких секций: скрытие и появление панелей мобильного браузера меняет динамический viewport и сдвигает текст и следующие секции во время прокрутки.

Текстуры главной закреплены отдельно от контента через `::before` с `position: fixed`, ограниченный секцией через `clip-path`. Для слоя фона используйте fallback `100vh`, затем `100lvh`: текстура сохраняет масштаб, когда панели браузера скрываются. Не возвращайте `background-attachment: fixed` для этой задачи.

`dvh` сейчас также используется для минимальной высоты внешнего контейнера страницы и ограничения открытого мобильного меню; не используйте его для секций главной. CSS и JavaScript должны использовать общий desktop-breakpoint `1101px`. Декоративные стрелки — inline SVG из `templates/partials/arrow-icon.html`, окрашенные через `currentColor`; не подменяйте их Unicode-символом или emoji.

Сохраните мягкое поведение `home-scroll.js` без перехвата обычной прокрутки колёсиком или касанием. Уважайте `prefers-reduced-motion` и сохраняйте естественную прокрутку страниц категорий, товара и длинных форм.

## Разделение интерфейсов

Публичный сайт использует перечисленные выше токены. Стили backoffice принадлежат `static/admin/` и не должны автоматически наследовать публичный фон или компоненты; детали админки — в [`backoffice.md`](backoffice.md).
